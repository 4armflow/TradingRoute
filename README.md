# เว็บไซต์กลุ่มเทรด Forex

เว็บหน้าเดียว ขึ้นบน GitHub Pages (ฟรี) ไม่ต้องมีเซิร์ฟเวอร์

## ไฟล์ที่ต้องแก้บ่อย

| ต้องการเปลี่ยน | แก้ไฟล์ |
|---|---|
| ชื่อกลุ่ม คำโปรย ลิงก์ LINE OA / YouTube / TikTok | `content.js` |
| เพิ่ม/ลบโปรโมชั่น | `content.js` (ส่วน `promos`) + รูปใน `images/promos/` |
| เพิ่ม/ลบรีวิว | `content.js` (ส่วน `reviews`) + รูปใน `images/reviews/` |
| โลโก้ | แทนไฟล์ `images/logo.svg` หรือใส่รูปใหม่แล้วแก้ `logo` ใน `content.js` |
| บทวิเคราะห์ประจำวัน | `brief.js` |

## ส่วนอื่นๆ

- ปฏิทินข่าวมาจาก TradingView อัปเดตเองอัตโนมัติ
- หน้ารวมรีวิวอยู่ที่ลิงก์ `#reviews` ต่อท้ายที่อยู่เว็บ
- รูปที่มีอยู่ตอนนี้เป็นรูปตัวอย่าง ให้แทนด้วยรูปจริง (ควรเบลอชื่อและรูปโปรไฟล์สมาชิกก่อน)
