# วิธีเพิ่ม / เปลี่ยน / ลบ โปรโมชั่น

โฟลเดอร์นี้คือรูปโปรโมชั่นบนเว็บ แก้ที่นี่แล้วเว็บจะอัปเดตเองภายใน 2–3 นาที

## เพิ่มโปร
1. กด **Add file → Upload files** (มุมขวาบนของหน้านี้)
2. ลากรูปมาวาง (jpg / png / webp) แล้วกด **Commit changes**

**ลำดับ:** เรียงตามชื่อไฟล์ ตั้งชื่อขึ้นต้นด้วยเลข เช่น `01-vip.jpg`, `02-live-nfp.jpg`

## ใส่ข้อความรายละเอียด (ไม่บังคับ)
สร้างไฟล์ `.txt` ชื่อเดียวกับรูป เช่น รูป `01-vip.jpg` → ข้อความ `01-vip.txt`
(กด **Add file → Create new file** พิมพ์ชื่อ `01-vip.txt` แล้วพิมพ์ตามแบบนี้)

```
หัวข้อ: สมัคร VIP ลด 30% เดือนแรก
หมดเขต: 30/11/2569
ปุ่ม: สมัครทาง LINE
ลิงก์: https://lin.ee/PU1pnU2
รายละเอียด:
- รับบทวิเคราะห์ข่าวทุกเช้า
- ไลฟ์คืนข่าวแรง
- ห้องถามตอบกับแอดมิน
```

- ทุกบรรทัดไม่บังคับ ไม่มีไฟล์ .txt ก็ได้ (จะแสดงแค่รูป + ปุ่มติดต่อ LINE)
- **หมดเขต** ใส่ได้ทั้ง `30/11/2569` หรือ `2026-11-30` เลยวันแล้วโปรจะหายจากเว็บเอง
- **ลิงก์** ต้องขึ้นต้นด้วย `https://` ถ้าไม่ใส่ ปุ่มจะไปที่ LINE OA

## เปลี่ยน / ลบโปร
- เปลี่ยนรูป: อัปโหลดรูปใหม่ชื่อเดิมทับ
- ลบ: กดที่ไฟล์ → ปุ่ม **…** → **Delete file** → Commit (ลบไฟล์ .txt คู่กันด้วย)

ไม่มีรูปในโฟลเดอร์เลย = แถบโปรโมชั่นจะซ่อนเอง
